# GEO 개선 요약

## 적용한 내용
- 홈 문구를 더 직설적으로 수정.
- `WebApplication` JSON-LD 추가.
- FAQ 페이지를 별도로 분리하고 홈에서 링크 제공.
- FAQ 페이지에 `FAQPage` JSON-LD 추가.
- README 첫 문단을 서비스 정의 중심으로 수정.

## 목적
- AI 답변 엔진이 서비스 목적을 빠르게 파악하도록 만든다.
- 사람과 AI 모두가 같은 서비스 정의를 읽게 한다.

## 확인 포인트
- 홈 화면과 README의 서비스 설명이 일관되는지.
- 구조화 데이터가 검색/요약 엔진에 읽히는지.
- FAQ가 핵심 질문을 충분히 담는지.
