# SEO 개선 요약

## 적용한 내용
- `<title>` 개선.
- `meta description` 추가.
- `viewport` 추가.
- Open Graph 메타 추가.
- Twitter 카드 메타 추가.
- `canonical` 추가.
- `robots.txt` 추가.
- `sitemap.xml` 추가.
- JSON-LD(`WebSite`) 추가.

## 적용 파일
- `src/main/resources/static/index.html`
- `src/main/resources/static/robots.txt`
- `src/main/resources/static/sitemap.xml`

## 기준 도메인
- `https://anymeal.net/`

## 확인할 것
- 페이지 소스에서 `canonical`, `og:image`, JSON-LD가 정상인지 확인.
- `https://anymeal.net/robots.txt` 접근 가능 여부 확인.
- `https://anymeal.net/sitemap.xml` 접근 가능 여부 확인.
- 카카오톡/슬랙 등 링크 미리보기 확인.
